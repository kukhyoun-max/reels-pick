# 요즘 본 릴스 알려줘

전주대학교 학생들이 실제로 반응한 릴스·쇼츠를 모으는 제보 폼입니다.

- `index.html` — 학생용 폼 (GitHub Pages로 배포)
- `Code.gs` — 비공개 구글 시트에 저장하는 Apps Script

## 연결 방법

1. 비공개 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용 붙여넣기
2. 배포 → 새 배포 → 웹 앱 (실행 계정: 나 / 액세스: 모든 사용자) → `/exec` URL 복사
3. `index.html`의 `GAS_URL` 값에 그 URL 붙여넣고 커밋
4. 학생에게 GitHub Pages 주소 공유

## 교차 평가 (평가하기 탭)

제보는 한 사람의 판단이라, 다른 조사자가 같은 영상을 보고 "우리 계정에서 보고 싶다 / 아니다"를 고른다.

- 평가 수가 적은 영상부터 10개씩 나온다. 내가 제보한 영상, 이미 평가한 영상, 스토리 링크는 빠진다.
- 「보고 싶다」를 누를 때 어울리는 계정(학교 공식·홍비디오·캐릭터 JJU)을 함께 고를 수 있다(선택).
- 「못 봄」(영상이 안 열림)은 다시 나오지 않고, 집계에서도 뺀다.
- 결과는 `교차평가` 탭에 쌓이고, 분석 탭 ⑧에 「보고 싶다 비율」 순위로 나온다. 평가 3명 미만은 「표본 적음」.
- 평가 탭으로 바로 여는 주소: `…/reels-pick/?mode=vote`

`Code.gs`를 고친 뒤에는 Apps Script에서 **배포 관리 → 기존 배포 수정 → 새 버전**으로 다시 배포해야 한다(새 배포를 만들면 URL이 바뀐다).

시트는 공유하지 않아 소유자만 볼 수 있으며, 제보는 Apps Script가 소유자 권한으로 대신 기록합니다.
